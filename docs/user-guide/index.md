# User Guide

The user guide is for choice modellers who want to apply a trained Delphos agent without working with the reinforcement-learning training machinery.

Start with the [choice modeller workflow](../choice_modellers/getting_started.md), then use the focused guides to:

- load a catalogue dataset or prepare your own data;
- generate candidate utility specifications;
- estimate candidates through Apollo;
- understand and export results; and
- control objectives and the modelling search space.

Researchers who want to train or fine-tune agents should continue to [Research & Papers](../research/index.md). Contributors working on the repositories should use the [Development guide](../development/index.md).
