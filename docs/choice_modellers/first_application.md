# First Application

This tutorial shows how to use a pre-trained Delphos to propose candidate utility specifications for the Swissmetro dataset.

By the end of this tutorial, you will:

- Load a pre-trained Delphos;
- Load a benchmark dataset;
- Run a specification search;
- Inspect the generated specifications.

---

## Step 1: Import Delphos

```python
from delphos import Delphos
```

## Step 2: Load a Pre-trained Agent

Load the default transport agent:

```python
agent = Delphos.load_pretrained("transport")
```

This agent has been trained on multiple transport choice modelling tasks and can transfer learned modelling strategies to new datasets.

---

## Step 3: Load the Swissmetro Dataset

```python
dataset = Delphos.load_dataset("swissmetro")
```

You can inspect the dataset:

```python
print(dataset)
```

Example output:

text Dataset: Swissmetro Observations: 10,719 Alternatives: Car, Rail, Swissmetro Attributes: Travel Time, Cost, Headway

## Step 4: Run a Specification Search

Generate up to 100 candidate specifications:

```python
results = agent.inference(dataset=dataset, num_specifications=100)
```

The `num_specifications` controls how many alternative utility specifications are proposed by Delphos. Larger values typically produce a wider range of candidate specifications but require more computation time.

## Step 5: Inspect the Pareto Front

You can inspect the Pareto front using the `plot_pareto_front()` method, which returns a dataframe with the candidate specifications and their associated model performance metrics. It shows the trade-offs between model performance (Log-likelihood) and model complexity (Number of parameters).

```python
results.plot_pareto_front()
```
