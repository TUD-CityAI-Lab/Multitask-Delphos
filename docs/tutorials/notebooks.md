# Jupyter Notebook Tutorials

For researchers and developers interested in the internal workings of the Delphos framework, we provide a series of Jupyter notebooks that guide you through each component step-by-step.

These notebooks are available in the `docs/tutorials` directory of the repository and can be explored interactively.

## Available Notebooks

### Delphos end-user tutorials

- [01. Getting Started](01_getting_started.md): Load Delphos, propose models, and inspect Apollo specifications.
- [02. Datasets and User Data](02_datasets_and_user_data.md): Understand bundled datasets and prepare your own CSV/schema.
- [02. Your Own Datasets](02_your_own_datasets.md): Walk through preparing and using custom datasets.
- [03. Modelling Space](03_modelling_space.md): Restrict the search space to transformations, tastes, covariates, and attributes.
- [04. Delphos Parameters](04_delphos_parameters.md): Tune search strategy, exploration, depth, seeds, and estimation flags.
- [05. Reward Function](05_reward_function.md): Understand the built-in reward and build project-specific ranking scores.
- [06. Quick Results](06_quick_results.md): Run a compact workflow intended for first results.
- [07. Robust Results](07_robust_results.md): Structure long, resumable runs for robust and best-model search.
- [08. Environment and Outputs](08_environment_and_outputs.md): Work directly with the Apollo/R environment, cache, and debugging outputs.

> [!NOTE]
> To run these notebooks interactively, you will need to clone the repository, install the framework dependencies, and ensure that your Python environment is properly configured.
